# StoryGraph

StoryGraph is an experimental narrative knowledge-graph tool derived from ideas and architecture used by Graphify.

The goal is to turn novels and story notes into a queryable relationship graph for AI coding agents such as Codex, OpenCode, and ZCode.

Instead of code entities such as functions and classes, StoryGraph focuses on characters, events, locations, objects, organizations, secrets, clues, foreshadowing, goals, beliefs, and chapters.

This repository is being developed as a novel-oriented adaptation. See `NOTICE` for attribution.
